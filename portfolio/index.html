FLAGSHIP 01 • CRYPTOGRAPHY & HARDWARE

Ghost-Tag

Offline-first encrypted NFC data vault across Android, web, and desktop hardware.
Repository Live Web Client Project Status

The Problem

Physical NFC tags are convenient but insecure by default. Anyone with an NFC-enabled smartphone can read unprotected user data, and lost or cloned tags expose sensitive credentials and recovery records.

What I Built

Ghost-Tag encrypts user data entirely client-side and writes authenticated AES-256-GCM ciphertext envelopes to physical NTAG213, NTAG215, and NTAG216 tags. It supports single-tag vaults, multi-tag bulk file vaults with erasure coding, BIP-39 recovery phrases, cross-platform Android and web interfaces, a desktop PC/SC and PN532 hardware bridge, and opt-in zero-knowledge cloud sync.

Security & Architecture Highlights

  • Two-Tier Key Hierarchy: Master passphrase derives an ephemeral KEK via Argon2id; random 256-bit CSPRNG generates DEKs per vault stored exclusively in AES-256-GCM wrapped form. Plaintexts and KEKs are zeroized in memory.
  • Tamper-Evident Envelopes: Additional Authenticated Data (AAD) binds envelope headers to prevent cross-tag swapping, purpose alteration, and length-extension attacks. Writes require byte-for-byte read-back verification.
  • Cauchy Reed-Solomon Erasure Coding: Shards bulk data over $\mathrm{GF}(2^8)$ across tag clusters, allowing deterministic recovery even if physical tags are lost or damaged.
  • Automated Quality & Security Gates: 347 Jest unit tests across 26 suites, 22 PN532 serial tests, CodeQL scanning, and TruffleHog secret leak prevention.
Explicit Threat Boundaries: Protects ciphertext confidentiality against RF interception and tag tampering. Does not claim forensic silicon erasure or root-compromised host defense. Released v2.0.6; v2.1.0 is unreleased staging.

FLAGSHIP 02 • SYSTEMS PROGRAMMING & BIOINFORMATICS

Genome Firewall (v2.0)

High-throughput C++ antimicrobial-resistance screening and decision-support engine.
Repository Architecture Spec Web Console

The Problem

Identifying antimicrobial resistance (AMR) superbugs from raw bacterial genomes requires scanning multi-gigabyte files against massive marker catalogs with mutation tolerance under strict compute budgets.

What I Built

As Project Lead and Core Architect, I engineered a pure C/C++14 systems pipeline that ingests raw FASTA genomes without external runtime dependencies, cross-references k-mers against indexed AMR catalogs, and generates tiered per-drug-class resistance predictions using an embedded logistic regression engine.

Engineering & Performance Highlights

  • Zero-Copy Memory-Mapped Parsing: Built FastaMmapParser leveraging virtual memory pages (CreateFileMapping / mmap) with 64 KB chunking and overlap buffers to prevent missed boundary markers.
  • 4-Ary Prefix Trie & Arena Allocator: Designed a compact 40-byte genomic trie node with an 8 KB arena block allocator, indexing 4,500,462 trie nodes from the 455-marker CARD catalog.
  • Fast Rejection Bloom Filter: Integrated a 1 MB Bloom filter with 3 hash functions for $O(1)$ negative sequence rejection, with Hamming distance $\le 1$ SNP tolerance.
  • Verified Benchmark Gains: On an AMD Ryzen 5 hexa-core system (GCC 6.3 -O3), v2.0 reduced trie arena memory by 78.3% (404.8 MB to 88.0 MB), cut inference scan time by 12x (263.27 ms to 21.99 ms), and cut total wall-clock time by 3.4x over the v1.0 baseline.
Scope & Clinical Notice: Defensive decision support only. Results must be confirmed through standard laboratory antimicrobial susceptibility testing.

FLAGSHIP 03 • APPLIED AI SAFETY & EVALUATION

CareSentry-AI

Deterministic safety harness for open-weight medical LLMs: attention probing, clinical invariant checks, and inference guardrails.
Repository Authors & Attribution Agent Skills

The Problem

Long clinical contexts dilute an LLM's attention to critical constraints buried in patient records, increasing the risk of missed drug allergies, adverse cross-reactivity, and unsupported treatment recommendations.

What I Co-Built

Co-developed a tri-layer safety harness that directly probes transformer multi-head attention weights, verifies clinical safety invariants against standardized ontologies, and enforces inference-time guardrails against prompt injection and hallucinated claims.

Harness & Invariant Architecture

  • Attention Probing & Z-Score Scoring: PyTorch forward hooks extract attention weights across final decision layers. Blockwise estimator runs in $O(S \cdot K)$ memory rather than $O(S^2)$ for contexts up to 24,000 tokens, with depth-stratified z-score controls.
  • Clinical Invariants Engine: Evaluates cross-reactivity, Cockcroft-Gault CrCl, CKD-EPI 2021 eGFR, Beers Criteria, drug-drug interactions, and reverse-omission detection across 180+ drug aliases via RxNorm Lite and WHO-ATC.
  • Defenses & Audit Trail: Prompt-injection defense (jailbreaks, roleplay, delimiter spoofing), invariant-guided constrained prefix-trie decoding, and a SHA-256 chained audit trail with 2.47 ms CPU latency.
  • Verification Evidence: 130 tests across all tracks (100% passing). Tested strictly against synthetic clinical datasets for local air-gapped deployment.
Attribution & Scope: Co-authored with Saksham Chawla & Chinmay. Evaluated on synthetic clinical datasets; designed as human-in-the-loop clinical decision support.
